DevFlow — адаптивный одностраничный сайт онлайн-школы программирования.

Проект выполнен в рамках контрольного задания №1 по дисциплине «SEO – оптимизация портальных решений».

Тема: Использование Flexbox для верстки сложных сайтов и порталов.

В работе использованы HTML5, CSS3 и JavaScript. Страница разделена на независимые смысловые блоки. Для построения сеток и расположения элементов применён Flexbox. Реализована адаптивная версия для компьютеров, планшетов и мобильных устройств. Добавлены элементы базовой SEO-оптимизации: title, meta description, meta keywords, семантическая разметка и атрибуты alt для изображений. Сайт опубликован на GitHub Pages. Код проверен в валидаторах W3C HTML и CSS — ошибок не обнаружено. Производительность и SEO проверены с помощью PageSpeed Insights.
